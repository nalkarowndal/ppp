# M2-2 Target AI Implementation Plan

> **For agentic workers:** use superpowers:executing-plans for the implementation, with RED→GREEN tests and one PR review before merging.

**Goal:** Implement deterministic, role-aware targeting and taunt/threat hooks without breaking M2-1.
**Architecture:** Pure target selector consumes immutable-ish references to live battle units; battle core owns actor state, timed flags, threat accrual and applies selector decisions. Keep all logic independent of rendering.
**Tech Stack:** Godot 4.7.2, GDScript, GitHub Actions.
**Spec:** docs/superpowers/specs/2026-11-10-m2-2-target-ai-design.md

## Global Constraints
- Only add to `feature/m2-2-target-ai` (stacked on `feature/m2-auto-combat-core`).
- M1 sandbox, UI, debug save, original character/enemy JSON unchanged.
- Seed/time tick compatibility; keep M2-1 regressions green.
- Do not merge into main before platform QA gates.

## Review Focus
- Death of taunter while combat continues should not force dead targets.
- An invalid taunt should not clear an active valid taunt.
- Multiple taunts on same team should have explicit replacement semantics.
- HP ties and threat ties must remain deterministic at every speed.
- Old enemy fixtures have a DEFENDER at slot 2 and must remain valid.
