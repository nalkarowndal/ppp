# M3-2 Equipment Design (2026-11-12)

Base: feature/m3-1-growth-progression (Draft #18). Head: feature/m3-2-equipment-system.

Goals: data-driven 4-slot loadouts, unique owned item instances, safe equip/swap/unequip, deterministic enhancement and additive stat preview integrated with M3-1 growth.

Schema: item definition {id,name,rarity,slot,flat_stats,percent_stats}; unique runtime item {instance_id,template_id,enhance_level,equipped_by,equipped_slot}; loadout {hero_id,weapon,armor,accessory_1,accessory_2}. Catalog built by strict validation. Current temporary catalog contains six templates only.

Policy: slots: weapon, armor, two accessories; rarity COMMON:+5, RARE:+10, EPIC:+15. No break chance. Preserve ownership and avoid cross-character duplication. M3-1 growth stats -> add each item's enhanced flat bonuses -> apply additive total percent bonus once. Strengthening grows only flat bonuses by 10% per level. Costs use gold plus enhancement stones under fixed provisional formula, no partial debit.

No actual battle UI, combat setup modification, item drops or persistent save until later stages; Superdesign UI integration belongs to M3-6. Keep Windows/Android physical QA incomplete. Do not merge main.
