# 아스트라 크로니클 — Game Design Document

- **Version:** 0.1 (M0 기준 기획, 검증 전)
- **Genre:** 서브컬처 캐릭터 수집형 픽셀아트 방치 RPG
- **Platforms:** Android 우선, Windows 개발·테스트, Web 확장 검토
- **Engine:** Godot 4.7 계열 / GDScript
- **Status:** design approved as initial baseline; implementation varies by milestone

## 1. 플레이어 경험

**약속:** 접속하지 않아도 기본 재화는 축적되지만, 의미 있는 캐릭터 성장과 편성·탐험 선택은 접속한 플레이어에게 남긴다.

플레이어는 부유도시의 탐사단 지휘관이다. 캐릭터를 모아 5인 파티를 만들고 고대 유적을 탐험하며 잃어버린 아스트라 문명의 비밀을 찾는다. 전투는 자동 진행되며 플레이어는 직업·속성·배치·궁극기 자동/수동 여부를 결정한다.

## 2. 핵심 루프

- **전투 루프 (초~분):** 5인 편성 → 자동 공격·조건부 스킬 → 승패 → 보상.
- **세션 루프 (5~15분 목표):** 오프라인 보상 수령 → 주요 캐릭터 강화 → 정체된 스테이지 재도전 → 선택적 던전/거점.
- **장기 루프 (일~주):** 신규 캐릭터·장비·스킬·거점 기능 획득 → 어려운 보스·던전 공략 → 스토리 진행.

## 3. 세계관 및 콘텐츠

대붕괴로 하늘에 흩어진 대륙과 별의 힘을 연구하던 아스트라 문명. 플레이어는 오래된 비공정과 부유도시를 복원한다. 세력은 탐사단, 루미나 학원, 황금기사단, 녹음의 수호자, 흑월 연합이다. 1장 '별이 잠든 숲' (1~20 스테이지), 2장 '무너진 황금도시' (21~40). 각 장 마지막에 보스 1종.

## 4. 전투 규칙

- 전열 2명 + 후열 3명, 실시간 자동 전투. 자동 기본 공격·액티브 스킬, 궁극기 자동/수동 토글.
- 기준 제한 시간: 일반 90초, 보스 120초. 속도: 1× / 2× / 3×.
- 직업: TANK/WARRIOR/ASSASSIN/MAGE/ARCHER/SUPPORT.
- 속성: FIRE/ICE/LIGHTNING/NATURE/LIGHT/DARK. 초기 상성: 화염>자연>번개>빙결>화염, 광휘↔암흑 우세.
- 결과: 적 전멸 승리, 아군 전멸/시간 초과 패배.
- 피해량, 상태이상·스킬·성장 수치는 [시스템 명세](../03_game_systems/system_balance.md) 참고.

## 5. 캐릭터 8인

| 이름 | 희귀도 | 역할 | 속성 | 실전 방향 |
|---|---|---|---|---|
| 아리아 | SR | 전사 | 화염 | 화상·지속 피해 |
| 세레나 | SSR | 마법사 | 빙결 | 광역 감속·동결 |
| 레온 | SR | 탱커 | 광휘 | 도발·보호막 |
| 루나 | SR | 지원 | 자연 | 치유·회복 |
| 카일 | SSR | 암살자 | 암흑 | 후열 단일 피해 |
| 리아 | SR | 궁수 | 번개 | 연속 사격 |
| 엘린 | R | 마법사 | 자연 | 독·광역 피해 |
| 벨 | R | 탱커 | 화염 | 도발·방벽 |

등급(R/SR/SSR)과 승급 단계(1~5성)는 서로 다른 값이다. 희귀도가 낮아도 편성 가치가 존재해야 한다.

## 6. 성장과 경제

레벨 1~100; 승급으로 상한 20/40/60/80/100 해금. 장비 무기·방어구·장신구 2칸. 재화: 골드·경험치 결정·승급석·스킬 서적·강화석·제작 소재. 오프라인 방치 정산 최대 8시간, 생산 기준 80% (초기 가설). 최초 클리어 보상은 반복 생산 보상과 분리.

## 7. 모드와 콘텐츠

| 모드 | MVP | 확장 |
|---|---|---|
| 메인 스테이지 40개·보스 2종 | 예정 | 지역 추가 |
| 성장 던전 2종 | 예정 | 무한의 탑 |
| 거점 기본 시설 1개 | 예정 | 경영 확장 |
| 방치 정산·레벨·장비 | 예정 | 전설·세트 제작 |
| 캐릭터 교류·호감도 | UI 진입만 | 개인 스토리/선물 |
| 생활·유적 로그라이크 | 제외 | P2 확장 |
| 길드·PvP·유료 뽑기 | 제외 | 별도 승인 |

## 8. 아트/오디오

일러스트는 고해상도 애니메이션풍, 월드는 선명한 도트 스프라이트와 패럴랙스 배경. 타일 16/32px 후보, 캐릭터 48×64 또는 64×96px 후보; 최종 픽셀 밀도는 M4 전 검증. 전투 VFX는 타격 가독성을 해치지 않게 제한. 음악은 마을 안정감·전투 속도감·보스 긴장감으로 구분.

## 9. MVP 범위 및 품질

8 캐릭터, 8~12 몬스터, 2 보스, 2 지역, 40 스테이지, 2 성장 던전, 1 거점 시설, 최대 5인 편성, 12개 UI 화면 구조. 필수 게임 플레이는 저장 후 재실행해도 보존되어야 한다. 중복 재화 지급 및 손상된 데이터 진행 불가는 Blocker.

## 10. 미결정/변경 관리

스킬 계수·성장 곡선·초기 능력치는 프로토타입 수치이며 최종 밸런스가 아니다. 모바일 해상도·픽셀 베이스·대상 기기·서버/수익화는 별도 검증이 필요하다. 미구현 기능을 README, PR, QA 리포트에서 구현 완료로 표기하지 않는다.
